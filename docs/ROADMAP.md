# Roadmap

Promoted work belongs here. Exploratory ideas remain in `RESEARCH.md` or
`DEFERRED.md` until they have an accepted release target.

## 0.3.0 — production-readiness hardening

- Configuration ownership and fail-closed installation.
- Concurrent private state and exact rolling-cost attribution.
- Locked local quality and release gates.
- Terminal-cell width and control-character safety.
- Accurate public documentation and review evidence.
- A cost-conscious CI design that remains disabled until runner policy and
  account capacity are available.

## Later

- Evaluate a native Codex compatibility helper when its hook payload and status
  widget contracts are documented sufficiently to test without inference.
- Evaluate Linux and macOS self-hosted runner deployment separately from the
  product package; do not make installation depend on CI infrastructure.
- Increase typed host-payload boundaries and coverage for hooks and installer
  orchestration without adding runtime dependencies.
